Actions
These four are the only actions. Every argument except name and times is an @ reference
to an object that a find node stored earlier (see The blackboard).
- Place(name, obj, location): puts obj at location. obj is graspable; location is an
  object that is not graspable, such as a box, crate, bowl, palette or test tube holder.
- Pour(name, source, target): pours the liquid in source into target. source contains a
  liquid; target is a container (a box, crate, bowl or other fixed object, or a graspable
  container such as a measuring cylinder or test tube).
- Shake(name, obj, times): shakes obj the given number of times. obj is graspable; times
  is a positive integer.
- Close(name, obj, closing_obj): closes obj with closing_obj. obj is a container that can
  be closed, such as a test tube; closing_obj is a cap or lid.
